# 笔驭工作台人话用法

## 怎么打开和往下走

1. 双击仓库根目录的 `start_biyu_ui.bat`。它会打开书架；选择一本书，再点“章节工作台”。
2. 页面横向分成五步：细纲 → 写作方案 → 生成正文 → 读稿与批注 → 评章摘句。完成当前步会自动切到下一步，也可以点回已经完成的步骤查看。
3. 每个灰按钮旁边都会说明现在为什么不能点。运行中会显示日志；失败会在页面上直接说原因，不会静默。
4. 阅读态会排版 Markdown；点“编辑”才进入文字框。方案没保存时，点“阅读”预览的是你眼前的新文字，不会跳回旧稿；标题会标“尚未保存”。
5. 方案改好后，主按钮是“保存并确认”；如果还想继续改，就点“仅保存”。切书、上一章、下一章或手填章号前若有未保存文字，页面会让你选择保存、放弃或留下。

## 已经有正文时怎么走

- 正式正文不会因为你改细纲或写作方案而失效，只会提示“基于旧方案”。新方案确认后，生成的是候选稿；你点“采用为正式正文”以前，机器不碰正式正文。
- 没有候选稿时，你可以直接编辑并保存正式正文；工作台会校验读到的版本、保存目标和当时盘面，并自动留一个 git 版本。
- 有候选稿时，正式正文只读，所有编辑都落到候选稿。这样不会出现你改正式稿、机器同时改候选稿的双头冲突。

## 怎么批注和修订

1. 候选稿生成后立刻进入“读稿与批注”，不必先采用。
2. 通过与不适用的检查折叠成“检查完成 N 项”；只有提醒和拦截才显示成问题卡。
3. 勾选本轮要改的问题，可以在每张卡下补一句自己的意见，也可以写整体意见。点“本轮忽略”会退出当前列表，但会留痕供以后总结口味。
4. 点“提交本轮修改”后，工作台先把这一轮的选择和意见落成一个修订包，再只调用写手一次。写手产出新候选稿，编辑重新审读，然后回到同一页。
5. 每一轮都重新选择、一次提交；不会为每张卡分别烧一次调用。

## 怎么摘句和评章

- 候选稿和正式正文都能摘句。鼠标选中文字后，点“好句 +1”或“问题句 +1”；侧边只显示数量，明细里可以改分类或移出当前列表。
- 摘句绑书、章和正文版本，正文后来再改也不会丢。它现在只是候选素材，永不自动升级成永久规则。
- 正式正文可以写章评。章评是你对整章的总判断；以后由工程对话归纳，仍须你人工点头才会变成检查器或规则。
- 章评保存后点“本章完成，进入下一章”。已有下一章会按实际进度落位；全新一章会预填细纲模板，但不会替你保存。

## 导演和修改历史在哪里

- 书籍详情页的“总导演”讨论全书方向、人物弧线和长线安排；同一本书重复点击会续接同一段对话。它先读本书材料，讨论节奏、爽点、开篇或卖点时才按问题选读 Craft 蒸馏稿，通用方法不能覆盖本书事实和你的拍板。
- 工作台“写作方案”页的“打开本章导演”只处理当前章；同一章重复点击同样续接。
- 页面底部“修改历史（只读）”直接读取现有 Git，显示初稿、手改、修订、采用和字数变化；这里只能看，恢复和删除留到后续版本。
- “本次运行详情”只在本次确实启动了导演、写作或修订时出现；失败会保持展开并在人话横幅里报错。

## 工作台背后的文件地图

一句话：工作台上每个动作背后都是文件；服务关了，文件还在。你亲手产的主要是细纲、方案修改、问题卡选择与意见、“采用”决定、摘句和章评，其余是机器产、你来判。

| 文件 | 谁写 | 谁读 | 用途 |
|---|---|---|---|
| `outlines/chN.md` | 你 | 导演 | 本章的题；没有它，后面不开始 |
| `logs/chN/planning.md` | 导演垫稿、你修改 | 写手、编辑 | 施工图；内容一改会自动回到待确认 |
| `chapters/_pending/chN.md` | 写手生成/修订，你可手改 | 你、编辑 | 候选稿；读稿、批注、摘句都可在这里做 |
| `chapters/chN.md` | 你采用候选后更新；无候选时也可直改 | 后续章节、跨章记忆、出书 | 书的正式正文；机器修订不直接写它 |
| `audit_reports/chN.json`、`chN.md` | 编辑与检查器 | 工作台、你 | 结构化问题卡与可读报告；通过项折叠，真问题成卡 |
| `logs/chN/revisions/round_k/` | 工作台打包 | 写手、你 | 一轮一件：问题、逐条/整体意见、方案、候选稿和版本 SHA |
| `判词/chN.md` | 你 | 你、中枢 | 对整章的总评，作为以后改善系统的慢反馈 |
| `样本库/正例候选.md`、`负例候选.md` | 工作台按你的摘句写 | 以后经你批准的写手/编辑 | 带版本的口味候选；不会自动晋升 |
| `consults/chapter_director_sessions.json` | 工作台 | 工作台 | 记住这章的导演对话，重复点击回到同一会话 |
| `consults/total_director_sessions.json` | 书籍页 | 书籍页 | 记住本书总导演对话；它不是章节运行状态，也不会假装正文正在生成 |

三条随手可验：刷新会重读盘上文件；服务停止后文件仍可直接使用；每次候选、采用和修订包都有版本留档。
