【Layer 3 写作约束】

# 篇幅
- 本章不少于 {min_words} 字。路线走完、停在该停的地方，就是写完了。
- 字数不够时，把最重的那一场写足：对白、动作、人物当下的感受。不加新事件、新场景、旁观者反应，不把同一件事写两遍。

# 标点与句式
- 正文不用破折号（——）。补充说明用句号断开；话被打断用省略号。
- 不写「不是 X，而是 Y」「不是 X，是 Y」，直接写 Y。
- 「缓缓 / 微微 / 轻轻 / 淡淡」能删就删。
- 不用 Markdown 符号；系统面板类文字用【】或纯文本。

# 认知与动作
- 每个角色只知道他此刻能合理知道的事；古人不知现代概念，不在场的人不知现场细节。
- 能力、速度不用精确数字。精确数字只用于剧情事实（期限、金额、人数）。

# 收尾
- 作者写了停在哪，就停在哪。
- 作者没写时，停在一个让人想翻页的具体时刻（一个动作、一句话、一个发现），不用总结、感慨或景物收尾，也不在收尾后另起一段回头讨论。
