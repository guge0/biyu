【Layer 3 写作约束 - 写完前自检】

# 篇幅
- 参考篇幅为 {target_words} 中文字符。先把本章戏核、关键转折和章末钩子完整写好，篇幅服从内容
- 情节已经自然收束时，允许短于参考篇幅；不得为凑字数重复描写、补无效过场、增加旁观反应或重启场景
- 只有细纲仍有关键事件未落地时才自然补足；通常不超过 {max_words} 中文字符
- 需要写厚时用加深手法(感官、内心、对白节拍、赌注、具体物件)，不用注水

# 标点用法(防 AI 文风)
- 破折号(——)仅限对话戛然停顿(如"这——"被打断)使用,
  禁止用于补充说明、句中转折、动作叙述。补充说明用句号 + 短句替代
- 反例:"是物理上的——空气变得滞重"
- 正例:"是物理上的，空气变得滞重"
- 正文不用 Markdown 符号:不加粗、不用井号标题、不用反引号;系统面板类文字用【】或纯文本

# 句式(成稿后会被逐条核对,写的时候就绕开)
- "不是X而是Y"——直接写后半句。反例:"他不是害怕,而是在等" 正例:"他在等"
- 明喻引导词(像/像是/仿佛/如同/宛如/犹如)全章最多 2 处,喻体要新鲜、具体、不抢戏
- 套话表情不进门:瞳孔一缩、嘴角上扬、心中暗道、不由得倒吸一口凉气——写成这个角色此刻才会有的具体身体反应
- "缓缓/微微/轻轻/淡淡"这类缓冲词,能删就删

# 视角与认知(防穿帮)
- 每个角色只知道他此刻能合理知道的事:亲眼见过、被告知过、或能推理出的
- 时代与身份限定认知:古人不知现代概念,未在场者不知现场细节
- 反例: 古代角色说"那都是后人编的"
- 正例: "那都是说书人瞎编"

# 动作与画面(防游戏化)
- 能力、速度不用精确数字描述
- 反例: "护腕在 0.3 秒内扣紧"
- 正例: "他几乎看不见护腕扣紧的过程,只感觉胸口一沉"
- 精确数字只用于剧情硬事实(期限、金额、人数等);写动作前确认角色当前的肢体位置和场景物件,动作要连贯

# 对话密度
- 非对话段落必须有动作、环境、心理、感官描写
- 温情/政策/铺垫章尤其要警惕"全章坐着说话"

# 章末完整性
- 章末段落收束后,不得续写场景重启段(回到更早时间点、重新讨论已发生事件)
- 反例:章末写了"大战开始了",后续还有段落讨论明天怎么打

# 笔墨分配执行
按细纲的笔墨分配执行——
关键处展开,文笔细一些、节奏慢一些;
过渡处节制,简练带过,不要把所有段落写得一样仔细。
细纲指明"特写""慢节奏""留白"等技法,在对应段落落地这些手法。

# 章末钩子(网文翻页率核心)
- 章末段落必须含有以下三项之一:
  1. 具体数字(如"存活人数 42/46""任务剩余 21:43:17""第 3 个伤口")
  2. 具体威胁信号(脚步声、林子里有动静、远方刀光)
  3. 具体身份揭示(某人是某身份、某物是某物的暗示)
- 禁止纯情绪/天气/景物作为唯一章末收尾
- 反例:"天快亮了。东南风还在刮。" (纯情绪)
- 正例:"天快亮了。东南风还在刮。系统提示又跳出一行字:存活人数 42。"

# 开篇要求
- 第一句必须是动作、对话或冲突
- 景物/环境描写最早从第 4 段开始

# 锚点核对
成稿之前,对照细纲中的"硬信息锚点块"逐条核对:
1. 读取锚点块中列出的每一条硬事实(时间/地点/人物/数字/约定/设定)
2. 检查正文是否已包含该条事实。包含的标准:正文中出现了该事实的关键信息(具体数字、具体名称、具体地点)
3. 任何缺失项必须自然融入正文补齐——不得以列举式堆砌,必须融入叙事(对话、叙述、角色视角均可)
4. 锚点的具体表述以锚点块原文为准,不得改写数字/时间/称谓
5. 核对完毕后输出正文,不输出核对过程
