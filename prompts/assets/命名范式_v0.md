# 命名范式 v0

**源**:起点 hotsales 榜 + 番茄 hot 榜(2026-07-04 缓存)在榜书名语料蒸馏
**维护**:中枢 **日期**:2026-07-06 **状态**:首版,基于扫榜缓存规则分析,每条带在榜例证。

> **用途**:为起名器 prompt 提供结构化命名范式参考,涵盖结构模板、题材差异与常见避坑。
> **天花板**:命名是创作行为,范式只提供"什么结构常见/什么字眼有效"的参考骨架,
> 不是硬规则——好书名往往靠超出规则的那一点创造力。
> **注意**:起点和番茄榜代表不同读者群,命名风格有系统性差异,下面分列。
> **全文消费者**:`biyu.ui.prompts_naming.read_paradigm_ref` → `build_naming_messages` → 起名 LLM；`biyu.ui.naming.generate_names` 同时把全文作为 `paradigm_ref` 返回给 UI。不给时真实 LLM 失去榜单范式参照。

## 一、起点风格(男频榜)

> **本节消费者**:起名 LLM（起点/男频候选分组、结构借鉴与理由标注）。

### 1. 四字或五字凝练型 — 最常见,占热销榜约 50%

【结构】二字核心意象 + 二字/三字场景或境界词

- **玄鉴仙族** — 玄鉴(法宝)+ 仙族(群体) → 仙侠家族题材
- **夜无疆** — 夜(氛围)+ 无疆(气势) → 东方玄幻
- **青山** — 双字极简,靠作者品牌力(会说话的肘子)撑辨识度
- **捞尸人** — 动词+人 → 职业型,传统灵异
- **剑烛大荒** — 剑+烛+大荒 → 武器+场景
- **赤心巡天** — 赤心(信念)+ 巡天(行动) → 古典仙侠
- **异度旅社** — 异度(空间)+ 旅社(地点) → 科幻时空穿梭
- **星河之主** — 星河(场景)+ 之主(身份) → 高武世界

### 2. 叙事感长句型 — 近年上升趋势,约 25%

【结构】设问/场景/冲突短语(5-9 字)

- **没钱修什么仙？** — 反问句,带调侃语气,修真题材
- **我正经学生，每天只吃九种魔药** — 第一人称反差,轻小说
- **苟在武道世界成圣** — "苟"字近年流行,东方玄幻
- **苟在两界修仙** — 同上模式 + 跨界设定,仙侠
- **我在永夜打造庇护所** — "我在+地点+动作",异世大陆
- **我的学习群里全是真大佬** — 第一人称+设定反转,都市生活
- **1984：从破产川菜馆开始** — 年代数字+冒号+起点描述,美食年代文

### 3. 三字或主语谓型 — 约 15%

【结构】主语(人物/概念)+ 简短谓语

- **诡秘之主** — 诡秘(风格)+ 之主 → 经典,已成 IP
- **以神通之名** — 介词结构,都市异能
- **元始法则** — 元始(时间)+ 法则(体系) → 异世大陆
- **廓晋** — 单字+朝代,极简历史文

### 4. 题材特征词分布

| 题材 | 常见字眼 | 在榜例证 |
|------|---------|---------|
| 仙侠 | 仙、玄、剑、苟、修仙 | 玄鉴仙族、苟在武道世界成圣、苟在两界修仙 |
| 玄幻 | 夜、荒、神、主、界 | 夜无疆、星河之主、元始法则 |
| 都市 | 我、学习、群、1984 | 我的学习群里全是真大佬、1984：从破产川菜馆开始 |
| 科幻 | 异度、旅、星、穿梭 | 异度旅社 |
| 历史 | 朝代名、晋、唐 | 廓晋 |
| 轻小说 | 我 + 反差设定 | 我正经学生，每天只吃九种魔药 |

**趋势**:起点榜 2026 年命名呈现明显的"苟"字系(苟在武、苟在两)和"我"字系(我的学习群、我正经学生)增长,反映读者对代入感和生存叙事的偏好。

## 二、番茄风格(女频为主混频榜)

> **本节消费者**:起名 LLM（番茄/女频长句与剧情钩子候选）；当前 UI 默认目标平台虽为起点，用户设想涉及番茄风格时仍作为对照语料。

### 1. 长句剧情预告型 — 占榜约 60%

【结构】8-15 字,概括核心梗或冲突,带情绪标签

- **不是疯批反派吗？怎么红眼要抱抱** — 设问+反差萌,甜宠
- **发配边关，罪妻开荒养出战神** — 场景+动作+结果,古代言情
- **塑料兄妹上啃老下啃小** — 关系+行为+夸张,现代言情无 CP
- **小可怜闪婚带娃大叔，三年后成首富** — 人设+事件+反转,豪门总裁
- **社恐小可怜穿成男主的捞子前女友** — 人设标签+穿越+剧情梗,系统文
- **穿成财阀太子爷的作精前女友** — 经典起手式,穿越+标签,甜宠
- **假千金绝症后，绑定糙汉续命** — 人设+危机+解决办法,系统文
- **穿书兽世：恶雌她终于吃上好的了** — 穿书+题材+反差点,兽世
- **误闯高门** — 四字短句,年代文;是番茄榜上少数短书名,因作者品牌

### 2. 剧情钩子+冒号/逗号分隔型 — 约 25%

【结构】前段设悬念/标签 + 分隔符 + 后段释悬念

- **睁眼！太子爷的恶毒女友重生了** — 叹号吸引 + 人设+题材,豪门总裁
- **对抗路？臭脸师弟他不停不哄** — 设问+人设互动,纯爱双男主
- **致命羁绊，京圈太子爷他极致偏爱** — 情绪词+标签+描述,穿越甜宠
- **十诫锁心** — 四字例外,强制爱题材;番茄榜上短书名少见
- **我在乱世靠换装系统装神女** — "我在+条件+手段+目标",穿越无 CP

### 3. 题材特征词分布

| 题材 | 常见字眼 | 在榜例证 |
|------|---------|---------|
| 现代言情 | 重生、闪婚、总裁、追妻、前女友 | 睁眼！太子爷、假千金绝症后、社恐小可怜 |
| 古代言情 | 边关、开荒、穿书、兽世 | 发配边关、穿书兽世 |
| 穿越 | 穿成、穿书、重生 | 穿成财阀太子爷、社恐小可怜穿成 |
| 甜宠 | 抱抱、偏爱、结婚 | 不是疯批反派吗、致命羁绊 |
| 系统 | 绑定、系统、续命 | 社恐小可怜、假千金绝症后 |

**趋势**:番茄榜书名普遍偏长(8-15 字),完整包含人设+冲突+看点,本质是"微缩版文案"。
读者靠书名就判断"这梗我吃不吃"。短书名(≤4 字)在番茄榜占比极低,
仅见于有作者品牌力或特殊定位(十诫锁心/误闯高门)时可行。

## 三、通用命名规律(跨平台)

> **本节消费者**:起名 LLM（跨平台结构选择、标点与第一人称范式解释）。

### 规律 1:起点重意象,番茄重剧情
- 起点读者看到书名就脑补世界 → 关键词驱动(玄鉴、巡天、星河)
- 番茄读者看到书名就判断剧情走向 → 梗驱动(疯批反派、绑定续命、假千金)

### 规律 2:四字格最安全,但长句型正在上升
- 起点:四字格仍为主流,长句型稳定在 25% 且有上升
- 番茄:第 6-15 字的长句已占榜 >60%,四字格少见
- **建议**:目标起点 → 优先四字凝练;目标番茄(女频)→ 用 8-12 字剧情预告

### 规律 3:疑问句/叹号开场增加点击
- 起点:没钱修什么仙？(反问)
- 番茄:睁眼！(叹号)、不是疯批反派吗？(设问)
- 疑问句和叹号在榜占比约 15-20%,尤其新书期有效

### 规律 4:第一人称"我"字开头的代入感
- 起点:我正经学生、我的学习群里全是真大佬、我在永夜打造庇护所
- 番茄:我在乱世靠换装系统装神女
- "我"字开头在双榜都稳定出现,尤其适合系统文/穿越文

### 规律 5:冒号/逗号/问号分隔双段信息
- 结构:【吸引注意的前段】+分隔符+【释悬念/扩信息后段】
- 例证:1984：从破产川菜馆开始、穿书兽世：恶雌她终于吃上好的了
- 优点:前段让读者扫读即判断是否感兴趣,后段深入说明

## 四、常见避坑

> **本节消费者**:起名 LLM（候选去重、平台错位、长度和文体匹配的自检依据）。

1. **过长的纯设定名词**(>5 字且无剧情暗示) → 读者扫过无感
   - 反面:宇宙纪元之星辰法则 → 四个抽象名词叠加
   - 正面:元始法则(两个词有对比张力)

2. **与平台风格严重错位**
   - 起点的 4 字凝练型书名 → 在番茄榜会被长句包围,失去竞争力
   - 番茄的 12 字微文案 → 在起点榜显得不够"有格调"
   - 建议:目标平台优先,跨平台时用副标题平衡

3. **跟风流行词但无实质内容**
   - 2026 年"苟"字已密集(苟在武道/苟在两界),再起"苟在XX"辨识度降低
   - 跟风可以,但需要有题材差异或新角度

4. **书名和简介/正文文体不匹配**
   - 轻松向书名(没钱修什么仙)配严肃正文 → 读者预期落差
   - 标题党型书名配平淡正文 → 弃书率极高

5. **超长书名(>15 字)不加停顿**
   - 移动端列表只显示前 10-12 字,过长书名后半截被截断
   - 例:父王，开门！本郡主闯祸回来啦(14 字,已接近上限)

## 五、推荐起名框架(按目标平台)

> **本节消费者**:起名 LLM（生成 8–10 个候选时的可直接套用结构）；占位模板候选仍由 `ui/naming.py` 的本地池生成，不单独解析本节。

### 起点(男频)
```
[核心意象 2 字] + [场景/身份 2 字]
例:玄鉴+仙族、诡秘+之主、星河+之主

慎用:苟(已过密)、我(偏轻松向,不适于正剧)
推荐:剑/玄/天/神/夜/荒 + 主/传/诀/纪
```

### 番茄(女频)
```
[人设标签 3-6 字] + [剧情梗/反转 3-8 字]
例:穿成财阀太子爷的作精前女友
   假千金绝症后 + 绑定糙汉续命

推荐:设问/叹号开场 + 轻剧透型梗
慎用:纯四字格(除非有作者品牌)
```

### 跨平台(双平台可能性)
```
[4 字核心] : [6-10 字剧情句]
例:1984：从破产川菜馆开始
优点:起点端看前段够凝练,番茄端后段补剧情吸引力
```
