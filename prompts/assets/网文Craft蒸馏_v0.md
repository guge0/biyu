## 一、喂 P6-2 题材模板:结构化骨架 ★核心

> **本节消费者**:当前由 Propose craft 模板与 UI `read_craft` 全文消费；旧 P6-2 专用题材模板路线已砍，不另接 `genre_structure_checker`。

### 1. 节奏曲线(字数锚点)
- 万字级高潮分布:约 1 万字一个小高潮、3 万字一个中高潮、6 万字一个大高潮。
- "局"的颗粒度:约三四章构成一个完整的局(开局 → 布局 → 解局),在局尾掐高潮;**不要每章都掐**(过密会让读者烦躁)。
- 章尾悬念:以 3000 字一章计,约写到 2500 字处就该开始铺章尾的钩子。
- → 这是 P6-2"节奏曲线"可以直接量化的骨架。

### 2. 目标体系(三层,是节奏的引擎)
- 长 / 中 / 短三层目标:开局 1 万字立短期目标;3 万字内立中期目标并完成几个短期;6 万字内立长期目标并完成几个中期。
- 升级体系之所以最抓人(修真 / 官场 / 网游),是因为它"可预知下一步、阶梯式上升",每次升级自带下一个目标。
- 升级体系天然缺中期目标 → 用"副本 / 任务"补中期。
- 必须**刻意提醒**读者下一步目标在哪(为读者指方向);但**禁止剧透结局**(作者提前掀盖子、预告人物结局是大忌)。

### 3. 爽点分类(六类,题材模板按题材选配)
1. 暧昧 / 情:先抑后扬,克制胜过露骨(一个吻 > 大段描写)。
2. 物品获得:先反复强化"这东西多重要、多难得"制造需求感,再让主角得到。
3. 养成:逆境成长,起点别太高;升级只在突破瓶颈时小爆发,**不要每次升级都写成高潮**。
4. 优越感:打脸 / 先抑后扬(注:此桥段已被写烂,慎用)。
5. 送菜流:制造一个比主角更强更幸运的"高大全",最终其资源 / 运气都归主角。
6. 主线本质 = "追求爽的过程"。
- 题材差异:不同题材的爽点偏好不同,模板应记录"本题材要什么爽点 / 忌什么"(例:多数读者厌恶主角的女人受辱、挚友被杀)。

### 4. 开篇结构(前 3 万字定生死)
- "凤头":开头简单精要,把场景 / 外貌 / 背景 / 等级体系一律推到第 5 章以后。
- 主角聚光:开头三千字出场人物压到 2–3 个名字,别让龙套抢主角存在感。
- 双伏笔:至少埋一长一短两条线;短线在 3 万字内揭开,促使读者回头重看开头(**读者回头翻找伏笔 = 成功信号**)。
- 瘦身:写完前 3 万字后,反写一段约 300 字的细纲,情节全部围绕它,删一切无用形容词 / 描写 / 设定(只对前 3 万字做)。

### 5. 创新模式(P6-2 题材库扩展时用)
- "回炉 / 弥补遗憾":把一个成熟的新写法套到另一个题材上,就是新书(创新不必从零造)。
- "更换升级体系":换力量阶梯的命名或结构(炼气→筑基…,或换成符咒 / 科技 / 卡牌 / 阵法)就能出新意。

## 二、喂"人味 / AI 痕迹检测":机械文笔锚点 ★硬约束可落地的少数情形

> **本节消费者**:当前由 Propose/UI 作为参考材料消费；现役 Auditor 不直接读取本文件，机器规则是否上岗只认各 checker 与埋雷，不以本节文字代替。

> 这本书**三处独立**痛批的毛病,恰好都是 AI 文本的典型痕迹——可直接作为痕迹检测器的确定性指标:

- **段落长度**:移动端阅读,约 100 多字的段落最易读;上千字 / 四五行的长段是硬伤。→ 检测**段落长度分布**。
- **标点 / 感叹号流**:把三个感叹号当句号用 = 每行都"高潮"= 没有高潮;长句不加标点是基础错误。→ 检测**感叹号密度、破折号密度、超长句比例**。
- **文笔的定义(关键)**:好文笔 = 流畅、无阅读障碍、轻松读懂,**不是**形容词堆砌的华丽。→ AI 常反着来(过度修饰),可作"**描写 / 形容词堆叠密度**"的代理指标。

> 注意:这些是**机械层**约束,适合硬检测 + 硬约束;"节奏好不好、有没有张力"那种靠范例感染(声纹),规则使不上劲。

## 三、喂 P6-11 大纲校验 / Editor 评判维度:"评书七维"(按优先级排序)

> **本节消费者**:当前由 Propose/UI 全文消费；P6-11 未实现，Editor 不直接加载本节，故这里只是未来 rubric 资产，不伪称已接线。

> 作者给的"评一本书"七个角度,本身就是一套**带优先级的质量 rubric**,可作 Editor 三视角与 P6-11 校验的对照清单:

1. 脸面:书名 / 简介 / 主角名是否好记、直入主题(第一印象)。
2. 基础(= 文笔):错字少、标点不乱、无逻辑硬伤、段落句子不过长(见第二部分)。
3. 主角聚光:主角出场是否够早够足、有无龙套抢戏。
4. 开头:前 3 万字是否抓人(见第四点开篇)。
5. 布局:起承转合 + 伏笔,达到"情理之中,意料之外"。
6. 情节:有无让人欲罢不能 / 印象深刻处。
7. 人物塑造:主 / 配 / 反角是否令人留印象、持续关注。

> 映射:维度 3/4/5/6 → Editor-A(网文编辑视角);维度 7 → Editor-B(角色顾问);维度 5 伏笔 → Editor-C(设定审计);整套有序框架 → P6-11 大纲校验的评分骨架。

## 四、阶段 A 远期备用:开书前定卖点 / 立意

> **本节消费者**:Propose craft 与 UI 会诊用于开书前卖点讨论；无独立阶段 A 模块读取，暂不另接线。

> (与当前 P6-2 无关,留给将来"开书前立项"那条线,呼应老板早前问的"开书前定核心卖点")

- 题材定位先问三件:读者群是谁、其阅读需求、喜欢 / 厌恶什么。
- 卖点 = 一个"可预知、阶梯上升"的核心目标体系 + 明确的差异化新意(回炉 / 换体系)。
- "脸面"(书名 / 简介 / 主角名)是卖点的外显,开书前就要能让人看完简介就开始脑补情节。
